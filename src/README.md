# FreeRTOS 태스크 구현 소스 (Src)

이 디렉토리는 FreeRTOS 선점형 멀티태스킹 환경에서 독립적으로 구동되는 4개 태스크의 소스 코드와 펌웨어 메인 엔트리 포인트를 포함하고 있습니다.

---

## 🧵 FreeRTOS 4-Task 실행 매트릭스

각 태스크는 명확한 역할 분담과 고정된 스케줄링 우선순위(Priority)를 부여받아 동작합니다:

| 태스크 명 | 우선순위 | 실행 주기 / 격발 조건 | 할당 스택 | 주요 역할 및 책임 |
| :--- | :--- | :--- | :--- | :--- |
| `Task_State` | **4 (최상위)** | 이벤트 구동형 (`g_sensor_queue` 대기) | 6144 Byte | **두뇌 FSM 엔진**: 6가지 상태 전이 평가, 히스테리시스 불감대 처리, CANalyzer 스타일의 정밀 타임스탬프 트레이스 로그 연속 출력 |
| `Task_Actuator` | **3** | 이벤트 구동형 (100ms 타임아웃 큐 수신) | 8192 Byte | **출력 드라이빙**: 1.3인치 SSH1106 OLED 화면 렌더링, 화재 시 0.5초 살수 / 1.0초 대기 펄스 루프 제어, 부저 경보음 출력 |
| `Task_Sensor` | **2** | 주기 실행형 (`1000ms`, `vTaskDelayUntil`) | 6144 Byte | **센서 데이터 취득**: MQ-135 4095 포화 가드, IIR 적응형 베이스라인 보정, 3샘플 중간값 필터링 및 IPC 페이로드 전송 |
| `Task_MQTT` | **1 (최하위)** | 주기 실행형 (`2000ms`) | 4096 Byte | **클라우드 연동**: Wi-Fi 및 MQTT 브로커(Cafe24 VPS / Mosquitto) 자동 재연결, 텔레메트리 및 긴급 이벤트 JSON 비동기 스트리밍 |

---

## 🔒 IPC 데이터 무결성 및 스택 안전성 (Safety Design)

1. **공유 메모리 변이 배제 (Zero Shared Memory Mutation)**:
   - 태스크 간 전역 변수를 직접 읽고 쓰는 것을 금지하고, FreeRTOS 메시지 큐(`g_sensor_queue`, `g_actuator_queue`)를 통한 **값 복사(Pass-by-value) 메시지 패싱** 방식을 채택하여 경쟁 상태(Race Condition)를 원천 차단했습니다.

2. **Adafruit GFX / OLED 렌더링 스택 오버플로우 방어**:
   - `Task_Actuator`는 깊은 C++ 가상 함수 호출 체인을 가진 그래픽 라이브러리를 다루므로, 인터럽트 워치독(Interrupt WDT) 크래시를 방지하기 위해 넉넉한 **8KB 스택**을 배정했습니다.

3. **네트워크 장애 격리 (Fault Isolation)**:
   - MQTT 통신(`Task_MQTT`)을 가장 낮은 우선순위(1)로 분리하여, Wi-Fi 신호 지연이나 클라우드 서버 단선이 발생하더라도 **화재 감지 및 펄스 분무 로직(우선순위 4, 3)은 0.001초의 방해도 받지 않고 무중단 독립 동작**합니다.
