# 스마트 클린 애쉬트레이(SCA) 통합 테스트 계획서

본 문서는 스마트 클린 애쉬트레이(SCA) 시스템의 기능적 신뢰성 및 하드웨어 연동 상태를 최종 검증하기 위한 통합 테스트 방법과 수행 절차를 기술합니다.

---

## 1. 테스트 목적
개발 완료된 FSM(상태 머신), 센서 드라이버 계층, FreeRTOS 태스크 간의 IPC 큐(`g_sensor_queue`, `g_actuator_queue`) 송수신 연동 상태를 확인하고 실제 흡연 부스 및 가전 구동 환경에서의 예외 안전성을 최종 검증합니다.

---

## 2. 테스트 환경 및 대상

### 2.1. 테스트 대상 모듈
- **입력 계층:** MQ-135(raw, baseline, diff), DHT22(temp_current, temp_rate), HC-SR04(ash_level_pct), 플로트 스위치(water_empty)
- **제어 계층:** FreeRTOS (`Task_State` P4, `Task_Actuator` P3, `Task_Sensor` P2, `Task_MQTT` P1)
- **출력 계층:** OLED 디스플레이, WS2812B RGB LED, F5305S MOSFET 펌프 펄스 제어, 능동 경보 부저

---

## 3. 통합 테스트 시나리오 목록

### [TC-01] 초기 기동 및 대기 모드 검증
- **수행 조건:** 수조에 물이 채워져 있고(`water_empty = false`), 공기 상태가 깨끗함 ($\text{Gas\_Diff} \le 50$).
- **예상 동작:**
  1. 기기 전원 인가 시 OLED에 `AQI: Good / Standby` 및 꽁초 적재량(%) 출력.
  2. WS2812B RGB LED에 차분한 초록색 무드 라이트 점등.
  3. IDLE 상태일 때만 가스 센서 Baseline 적응형 IIR 필터 갱신 ($\text{baseline} = \frac{\text{baseline} \times 9 + \text{raw}}{10}$).
  4. 펌프 및 부저 정지 유지.

### [TC-02] 흡연 상태 감화 시나리오
- **수행 조건:** 가스 센서 차분값 $\text{Gas\_Diff} (\text{raw} - \text{baseline}) > 50$ (Smoke Threshold 초과) 유입 상황.
- **예상 동작:**
  1. WS2812B RGB LED가 즉시 세련된 노란색 라이트로 천이.
  2. OLED 디스플레이 유해 수치 그래프 표출.
  3. 백그라운드 MQTT 통신 채널에 상태 변화 데이터 전송 개시.
  4. $\text{Gas\_Diff} < 30$ (히스테리시스 회복) 시 `SYS_STATE_IDLE`로 안전 복귀.

### [TC-03] 화재 위험 감지 ($dT/dt > 2.0^\circ\text{C/s}$) 검증
- **수행 조건:** 온도 변화율 $dT/dt > 2.0^\circ\text{C/sec}$ (`WARNING_RATE_THRESHOLD` 초과) 상황.
- **예상 동작:**
  1. 즉시 `SYS_STATE_WARNING` 모드로 전환됨.
  2. OLED "WARNING: FIRE RISK" 점멸, WS2812B 빨간색 깜빡임 경고.
  3. 부저가 짧고 지속적인 경보음을 출력하기 시작함.

### [TC-04] 화재 확진 (3초 Timeout) 및 펄스 소화 제어 동작
- **수행 조건:** $\text{Temp} > 50.0^\circ\text{C}$ (`FIRE_TEMP_THRESHOLD` 초과) 조건이 3초간 지속될 경우.
- **예상 동작:**
  1. `SYS_STATE_FIRE_DETECTED` 모드로 최종 확진 전이.
  2. OLED에 `!!! EMERGENCY DISCHARGE !!!` 경고 표시, WS2812B 빨간색 고속 점멸, 부저 긴급 사이렌 출력.
  3. 펌프가 **0.5초 ON $\rightarrow$ 1.0초 OFF 대기 루프** 펄스 주기로 동작하는지 검증.
  4. 소화 완료 후 $\text{Temp} < 40.0^\circ\text{C}$ (`SAFE_TEMP_THRESHOLD`) 도달 시 `SYS_STATE_IDLE`로 복귀 확인.

### [TC-05] 수위 감지 비상 예외 차단 (Dry-run Protection)
- **수행 조건:** 임의의 동작 도중 수위 센서 플로트 스위치를 LOW (`water_empty = true`, 물 고갈) 상태로 조작함.
- **예상 동작:**
  1. 펌프 구동 신호가 즉시 완전히 강제 차단(Force Lock)되는지 확인.
  2. OLED 화면에 `REFILL WATER TANK` 오류가 뜨고 WS2812B 보라색 경고등 점등 및 `SYS_STATE_ERROR` 진입 검증.
