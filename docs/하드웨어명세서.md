# 스마트 클린 애쉬트레이(SCA) 하드웨어 명세서

본 문서는 스마트 클린 애쉬트레이(SCA) 테이블탑 디바이스에 탑재된 컨트롤러, 센서 계층, 구동 스위칭 소자 및 기타 수동 부품을 포함한 전체 하드웨어 사양 및 정확한 핀 매핑(Pinout)을 정의합니다.

---

## 1. 제어 및 전력 연동 아키텍처

```
                                [상시 5V C-Type 전원]
                                         │
        ┌────────────────────────────────┴──────────────────────────────┐
        ▼ (독립 LDO 전압 분리)                                          ▼ 벌크 캡 (1000uF)
  [센서/I2C 버스 (3.3V/5V)]                                           [5V 워터펌프 모터 및 LED]
  - ESP32-S3 DevKitC-1-N8                                              - 5V 미니 펌프 + 다이오드 (GPIO18)
  - OLED Display (GPIO9 SDA, GPIO10 SCL)                                - WS2812B RGB LED 바 (GPIO4)
  - DHT22 온습도 센서 (GPIO11)
  - HC-SR04 초음파 센서 (GPIO6 TRIG, GPIO7 ECHO / 감압 분배 10k:15k)
  - MQ-135 가스 센서 (GPIO5 ADC / 감압 분배 10k:15k)
  - 플로트 수위 스위치 (GPIO8 Pull-up)
  - 능동 부저 경보 모듈 (GPIO17)
```

---

## 2. 하드웨어 세부 컴포넌트 및 회로도 핀 매핑 명세

| 구분 | 품명 및 규격 | 역할 | 정확한 GPIO 핀 매핑 | 수량 |
| :--- | :--- | :--- | :---: | :---: |
| **MCU** | ESP32-S3-DevKitC-1-N8 | Wi-Fi/Bluetooth 연동 및 FreeRTOS 메인 제어기 | - | 1 |
| **Display** | 1.3인치 OLED 디스플레이 모듈 | 실시간 AQI(공기질 지수), FSM 상태 및 Refill 경고 알림 화면 표출 | **SDA(GPIO9), SCL(GPIO10)** | 1 |
| **센서 계층** | MQ-135 유해가스/연기 감지 센서 | 실내 공기 상태 수집 및 담배연기 유입 검출 (IIR 필터링) | **Analog (GPIO5 / ADC1_CH4)** | 1 |
| | AM2302 (DHT22) 온습도 센서 | 흡연 부스 내부 미세 온습도 및 $dT/dt$ 온도변화율 모니터링 | **Digital (GPIO11)** | 1 |
| | HC-SR04 초음파 거리 센서 | 잔여 꽁초 가용량 측정을 위한 거리 계측 (0% ~ 100%) | **TRIG(GPIO6), ECHO(GPIO7)** | 1 |
| | 초소형 플로트 수위 스위치 | 안개 노즐 진압용 물탱크 물 부족 감시 (Active LOW, Dry-run 방지) | **Input Pullup (GPIO8)** | 1 |
| **액추에이터**| 5V 미니 워터펌프 모터 | MOSFET 스위칭 기반 0.5초 펄스 안개 미스트 고압 분사 | **PWM / Digital (GPIO18)** | 1 |
| | WS2812B Flexible RGB LED 바 | 디바이스 상태별 LED 라이팅 표출 (초록/노랑/빨강/보라) | **Digital (GPIO4)** | 1 |
| | 능동 부저 모듈 (BUZZER) | 화재 위험 및 비상 확진 시 긴급 시각/청각 경보 기동 | **Digital (GPIO17)** | 1 |
| **전력/회로** | F5305S PWM MOSFET 드라이버 모듈 | 워터 펌프 모터 고속 펄스 스위칭 드라이버 | - | 1 |
| | TXS0108E 8채널 양방향 레벨시프터 | ESP32(3.3V 로직) $\rightarrow$ WS2812B(5V 로직) 고속 신호 레벨 변환 | - | 1 |
| | 역기전력 방지용 다이오드 (1N4007) | 펌프 역기전력(Flyback) 발생 시 MCU 리셋 방지 루프 | - | 1 |
| | 벌크 캐패시터 E/C 16V 1000uF | 펌프 작동 시 전위 노이즈 필터링 및 전원 평활 | - | 1 |
| | 안전 감압 분배 저항 ($10\text{k}\Omega : 15\text{k}\Omega$) | MQ-135, HC-SR04 (5V 로직) $\rightarrow$ MCU (3.3V 안전 레벨) 감압 | - | 각 1 |

## 3. 회로 보호 및 안정성 설계 사양
- **GND 루프 최소화 및 역기전력 차단:** 모터 동작 전류 노이즈 유입을 막기 위해 전해 콘덴서($1000\mu\text{F}$)와 역기전력 다이오드(1N4007)를 MOSFET 드라이버 출력부와 모터 전원선에 밀착 배치하여 MCU 브라운아웃(Reset)을 차단함.
- **로직 감압 분압 저항:** MQ-135 아날로그 및 초음파 Echo 라인에 $10\text{k}\Omega : 15\text{k}\Omega$ 분압 회로를 직렬 배치하여, ESP32 GPIO 핀의 입력 전위 한계치(3.3V 이하)를 보장하고 칩 소손을 완벽히 방지함.
