# SCA (Smart Clean Ashtray) 하드웨어 조립 및 시스템 동작 설명서

## 🛠️ 1. 하드웨어 조립 및 회로 배선 가이드

### 1.1. 부품 연결 핀 맵 (Pinout Map)

ESP32-S3-DevKitC-1 보드와 각 센서 및 액추에이터는 아래 핀 맵에 따라 배선합니다. (`platformio.ini`에서 언제든지 핀 번호 변경 가능)

| 부품명 | 모듈 핀 | ESP32-S3 연결 핀 | 전원 공급 | 비고 및 보호 회로 |
| :--- | :--- | :--- | :--- | :--- |
| **MQ-135 가스 센서** | AO (아날로그) | **GPIO5** (ADC1_CH4) | 5V / GND | 분압저항 ($10\text{k}\Omega : 15\text{k}\Omega$) 적용 |
| **DHT22 온습도 센서** | DATA | **GPIO11** | 3.3V / GND | 10k 풀업 저항 적용 |
| **HC-SR04 초음파** | TRIG / ECHO | **GPIO6** / **GPIO7** | 5V / GND | ECHO 핀 분압저항 ($10\text{k}\Omega : 15\text{k}\Omega$) 적용 |
| **플로트 수위 스위치** | OUT / GND | **GPIO8** | MCU Internal Pull-up | Active LOW (물 부족 시 LOW) |
| **1.3인치 OLED** | SDA / SCL | **GPIO9** / **GPIO10** | 3.3V / GND | I2C 통신 (주소: 0x3C) |
| **WS2812B RGB LED** | DIN (Data In) | **GPIO4** | 5V / GND | TXS0108E 레벨시프터 신호 증폭 |
| **F5305S MOSFET (펌프)** | PWM / GND | **GPIO18** | 5V / GND | 1N4007 다이오드 및 1000uF 캡 병렬 배치 |
| **능동 경보 부저** | SIG / GND | **GPIO17** | 3.3V / GND | NPN 트랜지스터/드라이버 경유 |

### 1.2. 회로 조립 시 핵심 안전 주의사항

1. **전원 분리 및 벌크 캐패시터 배치**:
   - 5V 미니 워터펌프 작동 시 순간적인 전위 강하(Brown-out)로 MCU가 리셋되는 현상을 방지하기 위해 **16V 1000uF 전해 콘덴서**를 펌프 전원 입력 단자에 병렬 연결합니다.
2. **역기전력 방지 다이오드 (Flyback Diode)**:
   - 펌프 모터의 코일 역기전력이 MCU로 유입되는 것을 차단하기 위해 **1N4007 다이오드**를 펌프 모터 양단에 역방향으로 병렬 결선합니다.
3. **5V -> 3.3V 로직 감압 분압저항**:
   - 5V 전원으로 구동되는 MQ-135 아날로그 출력 및 HC-SR04 ECHO 출력이 ESP32-S3 핀 입력 한계치(3.3V)를 초과하지 않도록 **$10\text{k}\Omega : 15\text{k}\Omega$ 분압 회로**를 거쳐 입력되도록 구성합니다.

## 💻 2. 펌웨어 업로드 및 실행 방법

### Step 1. VS Code 및 PlatformIO CLI 준비
VS Code 터미널 또는 명령 프롬프트에서 프로젝트 폴더로 이동합니다.

### Step 2. 펌웨어 빌드 및 업로드
ESP32-S3 보드를 USB 케이블로 PC에 연결한 뒤 아래 명령어를 실행합니다.

```powershell
# 1. 펌웨어 컴파일 빌드
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e esp32-s3-devkitc-1

# 2. ESP32-S3 타겟 보드에 펌웨어 업로드
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e esp32-s3-devkitc-1 -t upload

# 3. 시리얼 모니터 관찰 (보드 전송 속도: 115200 bps)
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" device monitor -b 115200
```

## 🔄 3. 상태 머신(FSM) 및 FreeRTOS 구동 로직

### 3.1. FreeRTOS 4-Task 멀티태스킹 아키텍처

시스템은 하드웨어 안전성과 소화 실시간성을 보장하기 위해 4개의 독립 태스크로 작동합니다.

```
                    +-----------------------+
                    |      Sensor Task      |  (우선순위 2, 0.5초 정밀 수집)
                    +-----------------------+
                                | (g_sensor_queue)
                                v
                    +-----------------------+
                    |       State Task      |  (우선순위 4 - 최고, 뇌/FSM 제어기)
                    +-----------------------+
                     /                     \
   (g_actuator_queue)                       (State API)
           /                                   \
          v                                     v
+-------------------+                 +-------------------+
|   Actuator Task   |                 |     MQTT Task     |  (우선순위 1 - 최하,
+-------------------+                 +-------------------+   백그라운드 통신)
(OLED, LED, 부저,                       (원격 대시보드 송신)
 0.5s Pulse 펌프)
```

---

### 3.2. 상태 전이 조건 및 디바이스 작동 순서

#### 🟢 1. 대기 모드 (`SYS_STATE_IDLE`)
- **진입 조건**: 부팅 시 기본 진입 또는 공기질/온도가 정상화된 상태.
- **내부 동작**: MQ-135 센서 환경 적응을 위해 IDLE 상태일 때만 IIR 필터 공식으로 Baseline을 지속 갱신 ($\text{baseline} = \frac{\text{baseline} \times 9 + \text{raw}}{10}$).
- **출력 상태**: OLED "AQI: Good / Standby", WS2812B **차분한 초록 무드등**, 펌프/부저 OFF.

#### 🟡 2. 흡연 감지 모드 (`SYS_STATE_SMOKING`)
- **전이 조건**: $\text{Gas\_Diff} (\text{raw} - \text{baseline}) > 50$ (Smoke Threshold 초과).
- **출력 상태**: OLED 유해 수치 그래프 표출, WS2812B **세련된 노란색 라이트**, 백그라운드 MQTT 공기질 데이터 전송.
- **복귀 조건**: $\text{Gas\_Diff} < 30$ (히스테리시스 적용) 시 `IDLE` 복귀.

#### 🔴 3. 화재 위험 경고 모드 (`SYS_STATE_WARNING`)
- **전이 조건**: 온도 급증률 $dT/dt > 2.0^\circ\text{C/sec}$ 감지 시.
- **출력 상태**: OLED "WARNING: FIRE RISK" 점멸, WS2812B **빨간색 깜빡임 경고**, 부저 **짧고 지속적인 경보음** 출력.

#### 🔥 4. 화재 진압 모드 (`SYS_STATE_FIRE_DETECTED`)
- **전이 조건**: $\text{Temp} > 50^\circ\text{C}$ 조건이 3초간 지속될 경우 (Timeout 확진).
- **출력 상태**: OLED "!!! EMERGENCY DISCHARGE !!!", WS2812B **빨간색 고속 점멸**, 부저 **강력한 긴급 사이렌**.
- **소화 펌프 펄스 제어 (Pulse Control)**:
  1. 워터 펌프 0.5초간 분사 (High)
  2. 1.0초간 정지 후 온습도 재측정 (Low)
  3. 온도가 $40^\circ\text{C}$ 미만으로 내려갈 때까지 루프 반복.

#### 🟣 5. 비상 오류 모드 (`SYS_STATE_ERROR`)
- **전이 조건**: 수위 센서 LOW (물 부족) 발생 시 **어떠한 상태에서든 즉시 전이**.
- **출력 상태**: OLED "REFILL WATER TANK", WS2812B **보라색 경고 라이트**.
- **안전 보호 기능**: **워터 펌프 강제 Lock (Dry-run 모터 소손 완벽 차단)**.
- **복구 조건**: 물 보충 완료 시 `IDLE` 상태로 자동 안전 복원.
